## 1. 변경

### 1.1 기본값 따옴표 경고 `W_DEFAULT_QUOTED`
| 항목 | 내용 |
|---|---|
| 문제 | 문자열 기본값은 TermFlow가 방언에 맞게 따옴표로 감싼다. 입력에 `'N'`처럼 따옴표를 넣으면 따옴표까지 값이 되어 DDL이 `DEFAULT '''N'''`이 됐다 |
| 변경 | 기본값이 작은·큰따옴표로 감싸져 있으면 검증 경고 `W_DEFAULT_QUOTED`("기본값 'N'의 따옴표를 빼고 입력하세요") — 편집기 검증 바·DDL 경고 목록(라벨 "기본값 따옴표")·외부 연동 `table_validate`에 같이 나온다 |
| 연동 안내 | 에이전트 연결 시 안내문에 `defaultVal` 입력 규칙(문자열은 따옴표 없이, 함수는 `CURRENT_TIMESTAMP`·`CURRENT_DATE`만, 경고도 0건 목표)을 더했다 |

기존 테이블의 기본값은 바꾸지 않는다. 이미 따옴표째 저장된 기본값은 편집기에서 열면 경고로 보이므로 따옴표를 지우고 저장한다.

## 2. 업그레이드
v1.3.2에서 바뀐 DB·설정은 없다. 평소 절차(가이드 §6 Windows · §14.5 Linux)로 올린다.
```bash
sudo bash /opt/termflow/scripts/upgrade.sh /tmp/termflow-linux-1.3.3.tar.gz
```
