## 3. 2차 과제(설계서 §4.9 외)
- 표준 추가 가져오기(병합: 신규만 / 원본으로 덮어쓰기 / 건별), 원본과 차이 비교·[원본 값 반영], 템플릿 개정 알림(프로젝트 홈 배너).
- 프로젝트 소유자·세분 권한, 편집자 템플릿 게시 요청 → 시스템 관리자 승인.
- Oracle·MySQL DDL 방언과 방언별 회귀(G4 3방언).
- 동의어 관리(승계 리포트 `r04_synonym_candidates.csv` 415건이 입력), 다중 인스턴스 캐시 동기화(`LISTEN/NOTIFY`), 사용자당 세션 1개 옵션.
- G8 결과에 따른 홈 온보딩(D8), S1 엑셀 진입 단축(D7).

## 6. 첫 작업(사용자)
1. `http://localhost:8090` 로그인(`admin` / `.env`의 `TERMFLOW_ADMIN_PASSWORD`) → 비밀번호 변경 → 두 번째 시스템 관리자·실사용자 계정 생성.
2. 운영 인스턴스에서 S2 1회 확인: RMS › 테이블 › [새 테이블] → 컬럼 몇 개 Enter 자동완성 → 저장 → DDL(연습 테이블은 삭제).
3. 작업 스케줄러에 일 1회 백업 등록(가이드 §7).
4. 정정 담당: 검토필요 도메인 정정(STDV1·RMS, 가이드 §4.4) → 감소 건수 기록.
5. G8 사용자 테스트(참가자 3명) → `docs/수용_테스트_결과.md` §8.
6. 1·4·5 완료 후 legacy 스키마 삭제 결정(가이드 §4.6).
