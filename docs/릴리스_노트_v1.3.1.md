## 1. 변경

### 1.1 설명서(제품 `/manual`)
| 항목 | 내용 |
|---|---|
| 사용자 가이드 §9.4 | 에이전트로 테이블 하나를 설계한 실제 흐름 — 테이블명 제안 → 미등록 용어 확인·등록(기존 약어 관례) → 도메인 등록 → 컬럼 자동완성 → 기본컬럼 → 검증·저장 → 수정(version) → DDL. `…코드` 컬럼의 코드구분 후보는 다른 업무구분 코드일 수 있으니 확인하라는 주의 |
| 사용자 가이드 §9.5 | 연동 오류 응답별 뜻과 할 일(401 꺼짐·토큰 무효, 403·404, 409 저장 충돌, 422 검증, 429 한도) |
| §9.3 | 연결 설정을 바꾸면 새 세션에서 도구가 보인다 |

### 1.2 소개 사이트
- 기능 페이지에 **에이전트 연동** 영역, 설치 페이지에 **에이전트 연동(선택)** 절(서버 설정 · 토큰 발급 · 연결 설정). "하지 않는 것"에 서버는 모델을 호출하지 않는다는 줄과 연동을 켰을 때의 데이터 흐름을 적었다.
- 공개 사이트가 v1.1.2에 멈춰 있던 원인(배포 판정이 push의 마지막 커밋만 보던 것)을 고쳐, 직전 배포 이후 사이트 파일이 바뀐 push는 빌드한다. 이 판부터 판 이력에 v1.2.0~v1.3.1이 보인다.

## 2. 업그레이드
v1.3.0에서 바뀐 DB·설정은 없다. 평소 절차(가이드 §6 Windows · §14.5 Linux)로 올린다.
```bash
sudo bash /opt/termflow/scripts/upgrade.sh /tmp/termflow-linux-1.3.1.tar.gz
```

v1.3.0 §3과 같다.
