## 1. 새 기능

| 영역 | 내용 |
|---|---|
| Linux 서버 설치형 | `install.sh` 한 번 — Docker·compose 확인, 오프라인 이미지 적재, `.env` 생성(비밀값 3개 난수·권한 600·화면 출력 없음), systemd `termflow.service`(부팅 시 기동)·`termflow-backup.timer`(매일 02:00), `start.sh`로 기동·승계. `start.sh`·`scripts/backup.sh`·`scripts/restore.sh`는 Windows `.ps1`과 같은 동작. 가이드 §14 |
| 오프라인 번들 | `scripts/bundle.sh` → 소스(`git archive`) + 이미지(app·postgres) 파일 하나. 설치·업그레이드가 같은 명령(`.env`·백업·로그 유지) |
| 제품 내 설명서 | `/manual` — 빌드 때 `docs/사용자_가이드.md`·`docs/설치_운영_가이드.md`를 HTML로(목차·절 앵커·책 사이 링크·그림·코드 복사). 사용자 가이드는 로그인 전에도, 설치·운영 가이드는 시스템 관리자만. 진입점: 로그인 화면 링크, 상단 바 `?`, 사용자 메뉴 |

## 2. 변경·수정
- 판 1.1.0: 루트 `package.json` version(사이드바 표시), 이미지 태그.
- 첫 화면에서 레이아웃을 정하기 전(첫 이동 전)에는 아무것도 그리지 않는다 — 로그인·설명서 앞에 앱 셸이 잠깐 보이던 것 제거.
- 사용자 가이드: 캡처 파일 이름 표기를 실제 그림으로, 다른 문서 언급을 링크로(제품 안에서 이동).
