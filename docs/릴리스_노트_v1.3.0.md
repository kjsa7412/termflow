## 1. 변경

### 1.1 외부 에이전트 연동(CR-18)
개발자가 자기 에이전트(Claude Code 등 MCP 클라이언트)에 연결 설정 한 번으로, 화면과 같은 규칙으로 TermFlow를 쓴다 — 표준 용어·도메인 검색·등록, 컬럼 자동완성, 테이블 설계·검증·저장, DDL 생성.

| 항목 | 내용 |
|---|---|
| 개인 접근 토큰 | [내 계정] → **외부 연동 접근 토큰**에서 발급(30일~1년). 원문과 연결 설정은 발급 직후 한 번만 보인다. 토큰은 발급자 권한 그대로이고 변경 기록도 발급자 아이디로 남는다. 폐기 즉시 끊긴다. 계정 비활성화·비밀번호 초기화 시 자동 폐기 |
| `/mcp` | 에이전트 연결 주소 `http://<서버>:7340/mcp`(Authorization: Bearer 토큰). REST 기능 96개를 도구로 제공(로그인·비밀번호·토큰 관리·엑셀 일괄 등록 제외). 테이블 설계 순서 안내와 준비된 흐름 `design_table` 포함 |
| REST | 같은 토큰으로 `/api/v1/**`를 직접 호출할 수도 있다(쿠키·CSRF 불필요) |
| 기본 꺼짐 | 서버 `.env`의 `TERMFLOW_MCP_ENABLED=true`일 때만 동작한다. 에이전트를 거친 표준 사전·테이블 정의는 그 에이전트의 모델 서비스로 전송될 수 있으므로 사내 정보보호 기준으로 켠다 |

사용법은 사용자 가이드 §9, 운영 설정은 설치·운영 가이드 §3.2(환경 변수)·§12(보안 운영).

## 2. 업그레이드
평소 절차(가이드 §6 Windows · §14.5 Linux)로 올린다. 기동하면 마이그레이션 `0002_api_token`이 자동 적용된다(로그 `마이그레이션 적용 1건, 전체 2건`).
```bash
sudo bash /opt/termflow/scripts/upgrade.sh /tmp/termflow-linux-1.3.0.tar.gz
```
외부 연동을 쓰려면 설치 폴더의 `.env`에 다음을 넣고 그 폴더에서 app을 다시 만든다(쓰지 않으면 그대로 둔다).
```bash
TERMFLOW_MCP_ENABLED=true
```
```bash
sudo docker compose up -d app
```

## 3. 알려진 제한
- 엑셀 일괄 등록은 도구로 제공하지 않는다(건별 등록 도구 사용).
- 토큰 요청 한도(분당 600)는 서버 프로세스 메모리 기준이다(단일 인스턴스 운영 전제).
- 관리자가 다른 사용자의 토큰 목록을 보는 화면은 없다 — 계정 비활성화·비밀번호 초기화로 폐기한다.
- Release는 **초안**으로 만들어진다 — 첨부 파일을 확인한 뒤 게시한다.
