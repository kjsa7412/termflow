## 1. 변경

### 1.1 테이블 설계 가이드를 검증 경고로
외부 에이전트가 설계한 실 프로젝트가 검증 경고 0건인데도 기본컬럼 생략·도메인 없는 공통 키·코드구분 없는 코드 컬럼을 남겼다(가이드 §7). 가이드 위반 가운데 기계적으로 판정할 수 있는 것을 경고로 돌려준다. 편집기 검증 바·테이블 목록 경고 수·외부 연동 `table_validate`에 같이 나오고, DDL 생성 경고에는 넣지 않는다.

| 경고 | 조건 |
|---|---|
| `W_DEFAULT_COLS_MISSING` | 프로젝트 설정 "기본컬럼 포함"이 켜져 있는데 기본 세트 컬럼이 빠진 테이블. 테이블 설명에 `기본컬럼 제외`가 있으면 내지 않는다 |
| `W_MATCH_MANUAL` | 물리명·타입을 손으로 넣은 컬럼 |
| `W_MATCH_SIMILAR` | 유사 도메인을 다른 논리명으로 쓴 컬럼 |
| `W_CODE_CLS_NONE` | `…_CD` 컬럼인데 코드구분 없음(도메인이 있는 코드 마스터 키와 그 참조 컬럼은 예외) |
| `W_COMPOSED_KEY` | PK가 도메인 없는 조합 |
| `W_COMPOSED_SHARED` | 다른 테이블에도 있는 컬럼이 도메인 없는 조합 |

API(`table_create`·`table_save`)는 기본컬럼을 자동으로 넣지 않는다 — 요청과 저장 결과가 달라지지 않게 하고, 가이드가 허용하는 예외를 표현할 수 있게 경고로 알린다(CR-18 C11).

### 1.2 연동 안내문·설계 절차 스킬
| 항목 | 내용 |
|---|---|
| 안내문 | 클라이언트가 약 2천 자에서 잘라 끝부분이 보이지 않았다. 가이드 핵심 원칙 P1~P8과 기본값·오류·수정 규칙으로 바꿔 1,900자 이하로 줄였다 |
| 프롬프트 `design_table` | 준비 도구(역할·설정·기본 세트·도메인분류), 공통 키 도메인 우선, 완료 보고 표(매칭 통계·COMPOSED 사유·사전 변경·예외)를 더했다 |
| 설계 절차 스킬 | `docs/skills/termflow-table-design/SKILL.md` — 에이전트가 따를 단계별 절차. 설치는 사용자 가이드 §9.5 |

기존 테이블은 바꾸지 않는다. 올린 뒤 테이블 목록의 경고 수가 늘 수 있다 — 가이드 기준으로 설계를 다듬을 대상이다.

## 2. 업그레이드
v1.3.3에서 바뀐 DB·설정은 없다. 평소 절차(가이드 §6 Windows · §14.5 Linux)로 올린다.
```bash
sudo bash /opt/termflow/scripts/upgrade.sh /tmp/termflow-linux-1.3.4.tar.gz
```
