### 1.2 기본 표준 템플릿 상태 로그(CR-16 C15)
기동할 때마다 app 로그에 기본 표준 템플릿 상태를 한 줄 남긴다 — `기본 표준 STDV1 확인 — "TermFlow 기본 표준 v1"(ACTIVE), <적재 일시> 적재`(지웠으면 `… 없음 — … 적재 뒤 삭제됨`). 이미 적재된 설치도 로그로 적용 여부를 확인할 수 있다:
```bash
sudo docker logs termflow-app 2>&1 | grep "기본 표준"
```

## 2. 업그레이드
v1.2.0에서 바뀐 DB·포트·설정은 없다. 평소 절차(가이드 §6 Windows · §14.5 Linux)로 올린다.
```bash
sudo bash /opt/termflow/scripts/upgrade.sh /tmp/termflow-linux-1.2.1.tar.gz
```
- 번들을 손으로 풀고 `install.sh`를 실행할 때는 **번들을 설치 폴더에 먼저 풀었는지** 확인한다 — 풀지 않으면 `install.sh`가 이전 판을 그대로 다시 띄운다(`docker ps`의 이미지가 `termflow-app:1.2.1`인지 확인).
- v1.1.x에서 바로 올리는 경우의 템플릿 처리(승계 STDV1 → RETAILV1, 범용 STDV1 생성)는 v1.2.0 릴리스 노트 §2와 같다.

## 3. 알려진 제한
- 소개 사이트·설명서 그림은 이전 데모 데이터로 찍은 그대로다.
- Release는 **초안**으로 만들어진다 — 첨부 파일을 확인한 뒤 게시한다. Windows용 배포물(이미지 포함 zip)은 아직 없다.
