## 1. 변경

### 1.1 설계 절차 스킬 파일을 TermFlow가 제공
v1.3.4의 설계 절차 스킬은 저장소에서 받아야 해서 서비스 사용자가 받을 길이 없었다. 이제 서버가 같은 판의 파일을 내준다.

| 받는 곳 | 내용 |
|---|---|
| 주소 | `http://<서버>:7340/downloads/termflow-table-design/SKILL.md`(로그인 불필요) |
| 사용자 가이드 §9.5 | "설계 절차 스킬 파일(SKILL.md) 내려받기" 링크 |
| 내 계정 → 외부 연동 접근 토큰 | [설계 절차 스킬 내려받기](외부 연동이 켜져 있을 때) |
| 연동 안내문 | 단계별 절차 위치로 이 경로를 알려 준다 |

받은 `SKILL.md`를 에이전트 스킬 폴더(`<사용자 폴더>/.claude/skills/termflow-table-design/` 또는 작업 폴더의 `.claude/skills/termflow-table-design/`)에 두고 새 세션을 연다. 절차 내용은 v1.3.4와 같다.

## 2. 업그레이드
v1.3.4에서 바뀐 DB·설정은 없다. 평소 절차(가이드 §6 Windows · §14.5 Linux)로 올린다.
```bash
sudo bash /opt/termflow/scripts/upgrade.sh /tmp/termflow-linux-1.3.5.tar.gz
```

## 3. 알려진 제한
v1.3.0 §3과 같다.
