# TermFlow

**용어에서 DDL까지, 끊김 없는 한 흐름** — 표준 용어 기반 테이블 설계 · DDL 생성 서비스

[![ci](https://github.com/kjsa7412/termflow/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/kjsa7412/termflow/actions/workflows/ci.yml)
[![release](https://img.shields.io/github/v/release/kjsa7412/termflow?label=release)](https://github.com/kjsa7412/termflow/releases/latest)
![PostgreSQL 17](https://img.shields.io/badge/PostgreSQL-17-336791)
![Node 22](https://img.shields.io/badge/Node.js-22-339933)

표준 사전(용어·도메인·코드)을 **프로젝트마다** 두고, 컬럼 **논리명을 쓰고 Enter** 하면 표준으로 물리명·타입·코멘트가 채워진다. 설계가 끝나면 **PostgreSQL DDL**을 복사하거나 내려받는다.

[소개 사이트](https://termflow-about.vercel.app) · [화면 18장](https://termflow-about.vercel.app/screens) · [설치](https://termflow-about.vercel.app/install) · [판 이력](CHANGELOG.md) · [내려받기(Releases)](https://github.com/kjsa7412/termflow/releases/latest)

## 세 가지

| 표준 사전                                                                                                                                                                  | 자동완성 설계                                                                                                                                                             | DDL                                                                                                                                            |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 용어 ↔ 물리약어, 도메인(조각 + 접미어 분류 → 타입), 코드, 기본컬럼. 템플릿에서 복사해 **프로젝트마다 독립 사본**으로 둔다 — 한 프로젝트를 고쳐도 다른 프로젝트는 그대로다. | 논리명 Enter → **표준 · 비슷한 후보 · 조합 · 코드 · 미등록**. 사전에 없는 조각은 그 자리에서 물리약어를 넣어 등록(검토대기)하고 바로 쓴다. 관리자는 승인 큐에서 처리한다. | 저장 전에도 보이는 DDL 패널, 여러 테이블 내보내기(.sql · .zip · .tsv). TermFlow는 DDL을 업무 DB에서 **실행하지 않는다** — 담당 DBA가 적용한다. |

## 한 흐름 — 새 테이블 하나, 컬럼 열

1. **새 테이블** — 업무구분을 고르면 접두어(`ED_`)로 시작한다
2. **논리 테이블명** — 교육신청이력 → 물리명 `ED_EDU_REQ_HST` 제안
3. **컬럼 논리명 × 10** — 이름을 쓰고 Enter, 표준으로 물리명·타입·코멘트가 채워지고 다음 행으로
4. **PK · 저장** — Ctrl+S, 버전과 스냅샷이 남는다
5. **DDL 복사** — 오른쪽 패널의 [복사] 또는 .sql 다운로드

| 측정                    | 값             | 기준                                      |
| ----------------------- | -------------- | ----------------------------------------- |
| 입력 · 클릭 · 화면 이동 | **11 · 4 · 1** | ≤12 · ≤6 · ≤1, 브라우저 E2E 실측          |
| 자동완성 p95, 동시 20명 | **279.7ms**    | ≤300ms · 단독 83.8ms                      |
| 이관 테이블 DDL 실행    | **33 / 33**    | PostgreSQL에서 실행, 릴리스마다 회귀 검증 |

## 기능

| 영역           | 할 수 있는 일                                                                                                                                                                                        |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 프로젝트·권한  | 프로젝트마다 표준 사전·업무구분·테이블·멤버를 따로 둔다. 생성 마법사에서 표준 항목마다 원본을 템플릿 / 다른 프로젝트 / 비움 중에서 고른다. 보관(쓰기 잠금·복원) → 삭제                               |
| 표준 사전 7종  | 용어(승인·검토대기·반려) · 도메인분류 · 도메인(논리명·물리명·타입 자동 계산) · 코드구분 · 코드 · 기본컬럼 세트 · 승인 큐. 엑셀 일괄 등록(미리보기 → 적용), 모든 변경은 감사 이력                     |
| 테이블 편집기  | 논리명 Enter 자동완성, 미등록 조각 인라인 등록, 엑셀에서 여러 줄 붙여넣기, 저장마다 버전·스냅샷(이력·복원), 복제, 동시 저장 충돌 병합, 임시 저장, DRAFT → FINAL, 키보드만으로 전 흐름                |
| DDL            | PostgreSQL DDL — 테이블·컬럼 코멘트, 기본값, 코드성 컬럼 표현(코멘트 요약 · CHECK). 단일 .sql · 업무구분 폴더별 .zip · 정보 추출 .tsv, 내보내기 기록                                                 |
| 에이전트 연동  | 개인 접근 토큰 + MCP(`/mcp`) — 에이전트 도구가 내 권한 그대로 화면과 같은 규칙으로 표준을 찾고 등록하며 테이블을 설계한다. 결과는 서버 규칙 엔진이 낸다. 서버 설정으로 켜고 끈다(기본 꺼짐), v1.3.0~ |
| 제품 안 설명서 | 상단 바 ? 단추와 로그인 화면에서 여는 사용자 가이드(`/manual`), 역할별 사용법과 화면 그림. 설치·운영 가이드는 시스템 관리자에게                                                                      |
| 기본 표준      | 설치 직후 바로 쓰는 범용 기본 표준 템플릿 — 업무구분 10 · 용어 1,316 · 도메인 1,020 · 코드 541(국가·통화·언어·시도·은행 등)                                                                          |

### 역할 넷

| 역할            | 범위     | 하는 일                                                 |
| --------------- | -------- | ------------------------------------------------------- |
| 시스템 관리자   | 전체     | 계정 발급, 프로젝트 생성·보관·삭제, 템플릿 관리·게시    |
| 프로젝트 관리자 | 프로젝트 | 멤버·업무구분, 표준 사전 편집·일괄 등록·승인, 확정 해제 |
| 편집자          | 프로젝트 | 테이블 설계·저장·확정, 미등록 용어 인라인 등록, DDL     |
| 조회자          | 프로젝트 | 프로젝트 전체 조회, DDL 미리보기·복사·다운로드          |

멤버가 아닌 프로젝트는 보이지 않는다 — 주소로 들어가도 "찾을 수 없음".

### 하지 않는 것

- DDL을 업무 DB에 실행하지 않는다 — 생성만 하고, 적용은 담당 DBA가 한다
- PostgreSQL 외 방언(Oracle·MySQL)은 v1.x에서 만들지 않는다
- 표준을 고쳐도 이미 저장된 테이블을 몰래 바꾸지 않는다 — 편집기에서 경고와 [재적용]으로
- 외부 서비스로 데이터를 보내지 않는다 — 설치한 서버 안에서만 돈다(에이전트 연동을 켜면 토큰을 받은 사용자의 에이전트가 가져간다)
- 서버가 모델(생성형 서비스)을 호출하지 않는다 — 추천·물리명은 규칙 엔진이 낸다

## 설치

단일 앱 이미지 + PostgreSQL 17(compose). 기동할 때 스키마를 자동으로 맞춘다.

| 항목            | Windows PC                                                                 | Linux 서버                                                                                                                |
| --------------- | -------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| 요구 사항       | Windows 10/11 64비트, Docker Desktop 4.x(WSL2), Compose v2                 | Docker Engine + compose 플러그인 v2                                                                                       |
| 설치            | `start.bat` 더블클릭 — Docker·설정 검사 → DB → 초기 데이터 → 앱 → 브라우저 | `sudo ./install.sh` — 비밀값 난수 생성, 부팅 시 기동, 매일 02:00 백업                                                     |
| 인터넷이 없으면 | —                                                                          | [Releases](https://github.com/kjsa7412/termflow/releases/latest)의 오프라인 번들 `termflow-linux-<판>.tar.gz` 하나를 반입 |

- 공통: 메모리 2GB 이상 · 디스크 여유 5GB 이상, 브라우저 Chrome · Edge 최신 2개 판
- 첫 로그인: `http://<서버 주소>:7340`, 아이디·비밀번호는 `.env`의 `TERMFLOW_ADMIN_LOGIN`·`TERMFLOW_ADMIN_PASSWORD` — 비밀번호 변경 화면으로 바로 이동한다
- 운영: `pg_dump -Fc` 매일·14일 보관, 복구 스크립트 한 줄, 일 단위 로그 30일, `/health`(DB 포함) · `/metrics`

```bash
# Linux 서버 — Releases에서 받은 번들(.tar.gz + .sha256)을 /tmp/에 두고
cd /tmp && sha256sum -c termflow-linux-<판>.tar.gz.sha256
sudo mkdir -p /opt/termflow
sudo tar -xzf /tmp/termflow-linux-<판>.tar.gz -C /opt/termflow --strip-components=1 --no-same-owner
sudo /opt/termflow/install.sh
# 업그레이드(이미 설치된 서버) — 백업 → 풀기 → 새 이미지로 기동
sudo bash /opt/termflow/scripts/upgrade.sh /tmp/termflow-linux-<판>.tar.gz
```

전체 절차·`.env` 항목·백업·복구·업그레이드는 [설치·운영 가이드](docs/설치_운영_가이드.md).
