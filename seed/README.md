# seed

초기 데이터 승계(1차 legacy → 패션·유통 템플릿 RETAILV1, 2차 이관 프로젝트)의 원본 dump를 두는 폴더다. 원본은 실데이터라 **저장소에 올리지 않는다**(`.gitignore`) — 승계를 실행할 PC·서버에만 `seed/original/`로 둔다.

| 파일                                      | 용도                                                                                  |
| ----------------------------------------- | ------------------------------------------------------------------------------------- |
| `seed/original/dump-gen_table-new.sql`    | 승계 원본(수정 금지). `docker-compose.yml`이 `./seed`를 `/seed`로 읽기 전용 마운트한다 |
| `seed/original/*.sql`(나머지)             | 원본 시스템의 초기 데이터 스크립트(참고용)                                            |

- 원본이 없으면 `install.sh`·`start.sh`·`start.ps1`이 승계를 건너뛰거나 안내하고, 서버는 범용 기본 표준 템플릿만으로 기동한다(승계는 처음 설치 때 한 번만 필요).
- 원본이 없는 곳(CI·새 clone)에서는 원본을 읽는 테스트를 건너뛴다(`apps/server/test/local-sources.ts`).
